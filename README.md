# Code Editor

A browser-based code editor built using HTML, CSS, and JavaScript.

This project allows users to write and preview HTML, CSS, and JavaScript code directly in the browser through a simple interactive editor interface.

---

# Features

- Live code editing
- HTML editor
- CSS editor
- JavaScript editor
- Real-time output preview
- Responsive UI
- Browser-based execution

---

# Tech Stack

- HTML5
- CSS3
- JavaScript

---

# Concepts Implemented

- DOM Manipulation
- Event Handling
- Dynamic Rendering
- Live Preview System
- Responsive UI Design

# Run Project

1. Clone repository

```bash
git clone https://github.com/aniketwankhede8668/code-editor.git
```

2. Open project folder.

3. Run:

```text
Open index.html in browser
```

or use VS Code Live Server.
